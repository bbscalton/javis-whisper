Javis Whisper

An AI companion in your earbud. It listens to the conversation and quietly whispers corrections, facts, translations and answers that only you hear. Text only – no audio is ever stored.

⬇ Download for Android

Set up in 4 steps

  1. Install: tap Download on your phone, open the file and allow “Install unknown apps”.
  2. Battery: Settings → Apps → Javis Whisper → Battery → Unrestricted, so it keeps listening with the screen off.
  3. Pair: in the app open Settings, check the Server URL is https://whisper.neuereatec.org, enter the 6‑digit code from the server admin page and tap Pair once. This also loads the xAI key – no typing.
  4. Go: look for “Paired ✔ · xAI key received ✔”, connect your earbuds, choose a mode, add a pre-brief and press START (always visible at the bottom).

Modes

  • Coach – corrections, background and smart points during a conversation.
  • Translate – the English meaning plus a reply to say in their language.
  • Street – quick answers when passers-by ask you something.

Full guide and troubleshooting: bbscalton.github.io/javis-whisper
